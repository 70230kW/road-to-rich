# じゃんかね：ダーク・ニューモーフィズム

## 方針

黒に近すぎる背景では陰影が見分けにくいため、背景をチャコール `#272c33` に統一。左上の柔らかなハイライトと右下の影を、共通トークンで管理する。ゴールド、収支の正負、雀士カラー、段位の色は意味を保つ。

| 高さ | 使いどころ | 表現 |
| --- | --- | --- |
| 浮いた面 | 主要セクション、キャリア、対局会、設定 | 広く柔らかな二方向の陰影 |
| 操作面 | ボタン、ナビ、メンバーカード | 小さく近い陰影、押下で内側の陰影 |
| くぼみ | 入力欄、期間切替、指標のまとめ | 内側の陰影、選択中はゴールドの印を併用 |
| オーバーレイ | ヘッダー、ドロワー、モーダル、保存バー | 不透明な同素材と強めの落ち影 |

細かい指標・文章・行を再びすべてカードにするのではなく、まとまりのある領域だけに立体感を付ける。見出し、説明、内側の分析、表の行は平面に残す。ニューモーフィズムの弱点である「選択や入力の状態が影だけでは分からない」を避けるため、下線・チェック・フォーカス枠・エラー色を維持する。

## 実装境界

- `body.neu-theme` を本番HTMLと検証HTMLで有効化。テーマは `src/styles/neumorphic.css` へ集約し、既存の editorial / quality の後に読む。
- 認証、Firebase、保存アクション、順位・段位・精算の計算、データ形式は変更しない。
- TOPの1画面構成・スクロール禁止、書体、4原画、3Dマテリアル、ループ・ドラッグ、表彰台のスワイプは変更しない。
- 確認ポップアップの中央配置、既存モバイルシート、各オーバーレイの重なり順・スクロール・フォーカス処理も維持する。
- ネイティブのselect、checkbox、range、color入力は操作方式を変更しない。通常の入力をくぼませ、検索欄は二重のくぼみを避ける。
- 画像書き出し用カード自体にはテーマのカード・ボタンスタイルを適用しない。書き出しダイアログの外枠・操作はテーマに合わせる。
- `prefers-reduced-motion`、`prefers-contrast: more`、`forced-colors`へ対応。文字と地のトークン、主要操作の文字色は4.5:1以上を自動確認する（画面全体のアクセシビリティ監査を意味しない）。

## 検証

`npm test` / `npm run build` / `npm run lint` / `npm run test:changelog` / `git diff --check`。

追加テストは主要面のCSSOM、内側の平面、入力とネイティブ操作の分離、選択の非陰影キュー、Portalの確認操作、背景と文字のコントラスト、本番・検証エントリの一致、全14遷移先の実コンポーネントへの移動を対象とする。既存の入力・保存・再開・TOP・スワイプテストも実行する。
