# 3D麻雀牌ホーム — 実装・検証記録

## 修正: 明朝タイトルの可読性

- 「先頭の牌で中央の文字が消え、対局入力が読めない」という実機スクリーンショットを受け、文字と牌の静止位置を分離しました。
- 縦長の描画領域では上部をタイトル、下部を牌に割り当てます。横長では左をタイトル、右を牌にします。WebGL／原画フォールバックで共通の配置計算を利用します。
- 「対局入力」は「対局／入力」、「ダッシュボード」は「ダッシュ／ボード」の2行に変更しました。「順位表」「段位」は1行を維持します。文字の幅だけでなく行数と表示可能な高さからも大きさを制限します。
- 牌と文字の3D前後関係は残しますが、静止時にはタイトルの読む領域を先頭の牌で隠しません。牌の傾きと透視投影を含めた安全なサイズ・位置に調整しました。
- 実メッシュをカメラに投影する回帰テストを追加しました。描画領域320×280、320×450、390×500、440×555、768×680、1024×500、844×160で、傾き・動き低減の各設定においてタイトル領域への重なりが0、先頭の牌が領域内に収まることを確認しました。これは幾何テストであり、実ブラウザーの目視確認ではありません。
- 関連5ファイル27テスト・型チェック・ビルド成功。既存操作・入力下書き・TOPスクロール禁止は維持しています。実端末の文字描画は引き続き未確認です。

## 実装上の要点

- 順位表=赤伍萬、対局入力=發、ダッシュボード=七筒、段位=一索。
- 連続位置・targetを0〜3へ巻き戻さず、軌道だけを周期化。牌を距離で非表示にしません。
- 色は基準色から毎回計算。試作の `.025 + .975 * exp(-5 * depth)` を維持。
- 凹み深さ0.014、160×240の表面グリッド、共有外周、単一の法線傾斜を維持。
- ドラッグ後のsynthetic clickを遷移に使わず、移動7px以内の意図的なpointerupだけを判定。3Dは最前面の選択牌をレイキャストします。
- 牌とボタンの入力遷移は既存 `onOpenMatch` を使用。入力下書き・進行中の対局・入力中順位を維持。
- React stateはメニュー選択時のみ更新。フレームごとの値はeffect内で管理。
- 動きが止まるとRAF停止。画面非表示／スクロールアウト時も描画停止。画面離脱で画像読込を中断し、イベント・observer・GPU資源を解放。
- reduced-motionでは選択移動を即時反映し、ホバー傾きを停止。
- WebGL2非対応、モジュール／画像／描画エラー、context loss時は原画の代替表示と共通ボタンを使用。
- `touch-action: pan-y` と既存の `data-pull-ignore` を使い、縦スクロールとプルトゥリフレッシュの競合を避けます。
