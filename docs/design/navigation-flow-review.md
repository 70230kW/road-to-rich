# 導線・表示範囲のUXレビュー対応

## 対応範囲

黒ガラスの配色、3D牌、5つの下部タブを維持し、以下の7項目を変更した。認証・Firebaseの接続・保存形式・順位／収支／段位の計算式は変更していない。

| 対象 | 変更内容 |
| --- | --- |
| TOPへの復帰 | 共通ヘッダーに「TOPに戻る」を置き、サイドメニューと同じ `selectTab('top')` へ接続した。遷移時にメニューを閉じ、先頭に戻す。プルトゥリフレッシュがボタン・リンク・summary上のタップを横取りしないようにした。 |
| 対局入力 | 入口を「対局入力」に統一した。「1半荘だけ記録」「対局会を開始」「本日の精算」を分離し、単発は素点フォームへ直接遷移する。対局会の設定中は素点フォームと保存バーをマウントしない。保存バーは素点フォーム内の通常フローに置く。開始済みの会・下書き・入力中の順位は既存フローを使用する。 |
| 順位表 | ルームと雀士選択をヘッダー1行へ集約した。見出し直下に期間／密度／金額切替を配置した。3D表彰台は初期状態では閉じ、展開時のみ遅延読み込みする。目標表示は順位一覧の後へ移した。 |
| TOPメニュー | 下部の4つのメニュー名は1回で各画面を開くようにした。スワイプ・矢印・左右キーは引き続き選択だけを行う。戻った際は選択した牌を復元する。 |
| ダッシュボード | 冒頭で「個人成績／リーグ全体」を切り替える構成にした。選択中の対象と期間を明示し、0半荘の期間は「通算を見る」を表示する。通算段位と期間対象外の実績・目標・今月のハイライトを区別した。 |
| 最近の対局／履歴 | ホームは実参加の記録を先に絞り、最新3件を表示する。「リーグ全体」に切替可能。履歴の閉じた行に会名、日時、参加者、精算済みを表示する。未精算の会名・参加者・状態も表示し、年月／参加者の絞り込みを適用する。 |
| 段位一覧 | 現在の段位グループを初期展開し、雀士切替でも追従する。次の段位までの差額を一覧にも表示する。魂天は内訳が1段階しかないため同じ条件を二重表示しない。 |

この環境のChromiumは `socket() failed: Operation not permitted` で起動できなかった。権限の変更や回避は行っていない。したがって下記の目視・タッチ操作は未確認であり、マージ前にプレビューまたはローカルで確認する。

1. 320／390／768／1024px：ヘッダー1行の収まり、名前切替、TOP復帰、順位上位が最初に見えることを確認する。
2. iPhone Safari：TOP復帰ボタンを指で操作し、わずかな指の移動でも反応することを確認する。元の現象自体は今回の環境で再現できていない。
3. 単発と対局会設定を往復し、保存バーが設定に重ならないこと、入力・ソフトキーボード・暫定順位を確認する。
4. TOPの名前リンクは直接開き、スワイプと矢印では遷移しないことを確認する。
5. 表彰台の開閉、長い名前、段位一覧、モーション軽減、WebGL非対応表示を確認する。
