# 対局入力・共通UI・振り返り・直近分析

## 対象と境界

ユーザーが選択した改善案②③④⑤を実装。認証、Firebaseリポジトリ、保存形式、精算・段位の計算式は変更しない。①保存の原子性・同時更新対策と⑥メンバー復元・卓組みは今回の対象外。

TOPの構成、4枚の原画・3Dモデル、表彰台、5つの下部タブは維持する。

## 入力

- 素点欄の近くに「次の雀士へ」「入力を確認」。Enterも同じ動作で、自動保存はしない。
- 入力不備は未選択の雀士、重複雀士、未入力素点の順にフォーカスし、既存のインライン説明を表示。
- 合計、残り（自動計算分を含む）、自動計算値、未保存／保存中／保存失敗を既存の固定バーへ集約。
- 素点入力・履歴編集で、入力フォーカス時はモバイルのヘッダーを縮小し、下部ナビを一時的に隠す。暫定順位は残し、横にスクロール可能。
- VisualViewportの高さ・オフセットからキーボード下端の空きを計算。ピンチズームをキーボードと誤認しない。viewport未対応時も入力・通常のフォーカス移動は利用可能。
- フォーカス／resize／scrollの監視とrequestAnimationFrameは解除する。フォームが消えた場合はCSS側でも下部ナビを復元。
- 既存の下書き復元、負数、同点順位、役満、保存待機・再試行・取り消しは維持。

## 共通UI

- `quality.css`を既存スタイルの後へ追加し、通常のリーグ画面に限定したタイポグラフィ・余白ルールを定義。
- ページ見出しは太めの明朝体、説明と操作は既存のゴシック、数字は既存等幅書体とtabular-nums。
- 主要操作はゴールド、補助操作はニュートラル、破壊的操作は赤系。`NeonButton`の既存APIを維持し、多層グラデーション／常時装飾を削除。
- 長い雀士名は指定の名簿・順位・リザルトの行で折り返す。TOPや意味を持つ段位色・収支色を一括でリセットしない。

## 振り返り

- 精算後のリザルトに「振り返り」、履歴の展開後に「対局会を振り返る」を追加。必要時に遅延読み込み。
- 開始前から各半荘終了まで、保存済み`GameScore.point`を合算する。チップ・場代は含めず、現在の設定で再計算しない。
- 同額は競技順位方式で同順位。未対局の雀士は順位を付けず、途中参加・欠場の累計も保持する。
- 単独首位の交代、自己最高素点更新、既存の対局メモを表示。
- 自己最高は対象日の日時より前の記録＋それまでの半荘。未来の記録は参照せず、初回値を「更新」とは呼ばない。
- 左右スワイプ／ドラッグ、左右キー、前後ボタン、rangeで操作。縦スクロールを維持し、キャンセル・短いタップは進行しない。自動再生なし。軽い遷移はreduced-motionで停止。
- 表示のみで、Firebaseへの書き込みは行わない。

## 直近分析

- ダッシュボードの既存10対10の一文を、直近20半荘とその前の20半荘の比較へ拡張。
- 選択中の雀士・期間を使用。三麻と四麻は別々に集計し、混在時は切り替え可能。
- トップ率・ラス回避率・平均順位・半荘収支を、実際の対象数と開始／終了半荘を添えて表示。
- 両方20件に満たなければ参考値だけ表示し、差分を評価しない。未記録の率・金額は0とせず「—」。パーセントは小数1桁、率の差はptと明記。
- 率の比較バーは数値表と併記。直近の対象半荘だけを対局会ごとに合算し、金額の絶対値上位3件を表示（対局会全体の収支ではない）。
- 成績の変化のみを述べ、実力・攻守・打ち方を推測しない。

## 自動確認

`npm test`、`npm run build`、`npm run lint`、`npm run test:changelog`、`git diff --check`。

追加テストは計算の非重複・期間と雀士切替・三麻四麻・同額・途中参加・未来記録除外・読み取り専用の接続・スワイプ／キーボード・入力移動・viewport監視の解除を対象とする。CSSOMはルール適用の検証であり、実際のレイアウトやiPhoneキーボード挙動の確認ではない。
