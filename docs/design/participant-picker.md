# 対局会の参加メンバー選択と牌の太字表示

## 対局会の参加メンバー選択

- 名前の長さによって並びが崩れるチップを廃止し、名前・色マーカー・チェック位置が揃う行へ変更しました。
- 狭い画面では1列、選択欄の幅が560px以上なら2列です。長い名前は省略せず折り返し、行全体をタップして選択できます。最低行高は56pxです。
- 初期状態を未選択にし、参加する雀士を明示的に選びます。全員参加なら「全員を選択」で一括選択できます。
- 選択人数と登録人数、検索、一括選択／クリア、「選択済みのみ」の確認を追加しました。
- 検索は部分一致で、全角／半角・カタカナ／ひらがなの違いを吸収します。読み仮名データは持たないため、漢字の読みでの検索は行いません。
- 絞り込みは選択状態を変えません。「全員を選択」「選択をクリア」は表示中の結果だけでなく登録雀士全体が対象です。選択順で行を並べ替えないため、タップ位置は安定しています。
- 一覧内だけをスクロールでき、検索と選択人数、開始ボタンが長い名簿に押し流されない構成です。プルトゥリフレッシュの対象外にします。
- 開始ボタンに参加人数を表示します。3人／4人麻雀の設定に合わせ、不足人数、開始可能、会名未入力を案内します。
- 保存中は会名・検索・チェック・一括操作・開始ボタンを無効化し、失敗時は選択と会名を保持して再試行できます。
- 削除された雀士は参加人数・送信IDから除外します。新規登録された雀士は勝手に参加扱いにしません。
- 既存の開始API、半荘・順位計算、進行中セッション、解除確認、精算のフローは継続利用します。

## 牌の文字

- 大きな頭文字は明朝体の900ウェイトにしました。OSに極太明朝がない場合も太く見えるよう、同色の細いストロークを重ねます。字体を新しく描き替える処理ではありません。
- 牌上の名前と順位番号も明朝体の700ウェイトに統一しました。代替表示の文字も太字にします。
- 牌・台座の形状、スワイプ切替、拡大率、カメラ、読み込み時のちらつき対策は変更しません。

## 検証

- 検索と選択の保持、一括操作、選択済みフィルター、0人／長い名前／名簿の非同期更新。
- ネイティブチェックボックスのSpace操作、行タップ、検索クリア後の入力フォーカス。
- 3人／4人の開始条件、会名、選択したIDの送信、保存中ロック、エラーからの再試行、進行中の解除確認。
- CSSOMで行の整列・最低高・名前の折り返し・検索欄16px・一覧スクロールを確認します。
- Canvasの描画APIで頭文字・名前・順位に使うフォント、ストローク、文字列を確認します。

実ブラウザーから開発サーバーへの接続制限により、目視検証は未実施です。PRプレビューでは320 / 390 / 768 / 1024pxの幅で、長い名前・検索・一覧スクロール・保存の操作感を確認してください。iPhoneでは牌の明朝体の太さと検索フォーカス時の表示を確認してください。CSSOM／GPU境界のテストは実機の描画確認を代替しません。
