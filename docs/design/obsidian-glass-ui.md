# じゃんかね：OBSIDIAN / JADE

## 方向性

PR #100のニューモーフィズムを置き換える。PR #99のブラック（リーグ `#0b0d10`、TOP `#090d10`）を戻し、黒いガラスと翡翠色のシグナル、真鍮色の決定操作で構成する。麻雀牌の緑背・白い陶器・明朝体と、現代的な操作面の対比を残す。

| 要素 | 表現 | 役割 |
| --- | --- | --- |
| 地 | PR #99のブラック、静かな翡翠・金の環境光 | 大部分は黒のまま |
| 主要面 | スモークガラス、細い反射縁、片方向の浅い艶 | 情報のまとまり |
| ナビ・ポップアップ | 黒い透過面と背景ぼかし | 上下の層を区別 |
| 選択中 | 翡翠の下線・チェック・小さなブルーム | 現在位置・操作対象 |
| 決定操作 | 控えめな金、暗い文字 | 開く・開始・保存 |
| 危険操作 | 赤い縁と文字 | 削除・解除・入力エラー |
| 見出し・データ | 既存の太い明朝体、等幅数字、開放的な行 | 読む領域は装飾を抑える |

ニューモーフィズムの盛り上がり・大きな二方向の影は撤去する。ネオンの長方形や装飾用英語、常時走査線、追加パーティクルは増やさない。TOPの4原画、牌の質感、ループ軌道、タイトル書体、余白、縦スクロール禁止を変えない。

## 実装・性能・読みやすさ

- `body.glass-theme` と `src/styles/obsidian-glass.css` を本番・QA両方で使用。古いテーマは併用せず削除する。
- CSSの意味付きクラスだけを対象とする。内側の分析・一覧・指標を二重のガラスで囲わない。画像書き出し用カードや3Dモデルのマテリアルは変更しない。
- `backdrop-filter` は `@supports` 内で有効化し、ヘッダー、ナビ、ポップアップ、固定バーと3種類のヒーローだけに制限。大量の行・入力・WebGL・全画面背景はぼかさない。Safari用プレフィックスあり。
- 背景ぼかし非対応時は不透明な黒い面へフォールバック。`prefers-reduced-transparency`、`prefers-contrast: more`、`forced-colors` では背景ぼかしを切り、主要面を不透明にする。
- ブルームだけで選択を示さず下線／チェック／太さを維持。通常のフォーカスは翡翠色の2px枠。入力エラーは赤、disabledは減光。ネイティブのselect／checkbox／range／colorの挙動は維持。
- 通常文字・補足文字・アクセント文字と背景のトークン、金のボタン文字のコントラストを自動検査。ガラスの背後を白にした保守的な合成色でも4.5:1以上を確認（全画面のアクセシビリティ適合を保証するものではない）。
- 既存の季節パレット処理・データは残す。今回のテーマ適用中はbodyスコープでUI用cyan/blue・glowトークンを翡翠色に固定し、季節による配色の衝突を避ける。収支の正負、雀士の個別色、段位色のクラスは上書きしない。
- 新規アニメーション・依存パッケージ・描画ループなし。`prefers-reduced-motion`で操作面の遷移を止める。
- 認証、Firebase、入力・保存、精算・段位計算、ナビ、対局再開・入力中の順位確認を変更しない。
