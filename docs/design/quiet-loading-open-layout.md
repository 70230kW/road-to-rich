# 3Dの読み込み表示と、枠に頼らない画面構成

## 変更方針

- TOP・順位表の3D表示を `loading → webgl / fallback` の3状態に分離しました。読み込み中に簡易牌を見せず、初回の描画成功後に3Dを短くフェードインします。
- 通常の読み込みでは450ms後に小さな線と「3Dを準備しています」のみ表示します。高速な読み込みでは表示されません。動きを減らす設定ではフェードを使用しません。
- WebGL非対応、モジュール・アセット・描画の失敗、コンテキスト喪失時には従来の代替表示へ切り替えます。読み込み中もメニュー名と開くボタンは利用できます。
- 牌の原画・彫り込み・軌道・自由回転、独立TOP、5つの下部タブ、入力・保存・認証・集計ロジックは変更しません。

## プレゼンテーション層

`src/styles/editorial.css` を既存スタイルの後に読み込みます。用途が明確なクラスにだけ適用し、全要素に対する `border` / `background` のリセットは行いません。

| 画面・要素 | 整理内容 |
| --- | --- |
| 共通見出し・集計 | 外枠、色付き背景、箱型アイコンを外し、見出しと数値の強弱で構成しました。 |
| リーグホーム | キャリア・対局・補助情報を余白と上辺の区切り線で整理しました。 |
| 順位表 | 表彰台の外枠を外し、順位の選択線と戦績・3Dを直接表示しました。 |
| ダッシュボード・リーグ分析 | グラフ・活動カレンダー・目標・月間指標・対戦成績などを開いたセクションにしました。 |
| 対局入力・精算 | セクションと座席の外枠を整理し、編集中の座席は上辺の色で識別します。 |
| 対戦履歴 | 日別アコーディオンと精算結果を行形式にし、横線を残しました。 |
| 段位・実績 | 段位一覧、各雀士の進捗、トロフィーを区切り線で整理しました。獲得状態の色・アイコンは残します。 |
| 雀士登録・ルール・設定 | セクション外枠と重複した入力欄周囲の囲いを整理しました。 |
| シミュレーター・シーズン | 試算・過去シーズン・主要指標を行と余白で整理しました。 |
| アプデ | サイドメニュー・本文・表の外枠を整理し、項目の区切り線を残しました。 |
| 期間・情報量の切替 | 背景付きのトレーから、選択項目の下線へ変更しました。 |

保持する境界：入力欄、主操作ボタン、確認ダイアログ、エラー・警告、固定ヘッダー／下部ナビ、共有画像。これらは操作対象、前後関係、安全性を示すために必要です。

## 自動確認

- TOPの初回読み込みで代替牌が非表示、描画成功前にはreadyにならないこと。
- 読み込み待ちの選択・遷移、初回描画失敗、コンテキスト喪失、遅延解決後の破棄。
- 順位表でも読み込み中の代替表示を出さず、同期的な初回描画後にreadyになること。
- 既存のスワイプ・回転・キーボード・画面外停止・GPU資源解放・ナビゲーション。
- 30種類の表示クラスをCSSOMで検証し、外枠／角丸／影を除去しつつ、フォームとダイアログの境界、指標の詳細ボタンを保持すること。
- アプデ画面のテストは固定バージョンではなくデータ上の最新バージョンを確認するよう修正しました。履歴自動生成後の誤検知を防ぎます。

## 未確認・プレビューでの確認手順

この環境では実ブラウザーから開発サーバーに接続できないため、実GPU描画、iPhone実機、スクリーンショット比較は未確認です。CSSOMテストはレイアウト・画質の目視検証を代替しません。

1. キャッシュを無効にし、低速回線でTOPを開く。簡易牌が挟まらず、完成した3Dだけが表示されること。
2. 順位表でも1〜3位を切り替え、初回読み込み・自由回転・正面復帰を確認する。
3. 320 / 390 / 768 / 1024px幅で上記の全画面を開き、文字切れ、横はみ出し、操作範囲の不足がないことを確認する。
4. 入力・精算・登録・削除確認・期間変更・詳細モーダルが従来通り使えること。検証用データを使い、本番データを変更しない。
5. reduced-motion設定、WebGL無効、3Dチャンク／画像の読み込み失敗でも操作できること。
6. TOPは引き続き全画面・縦スクロールなし、その他の画面は縦スクロールと5タブを維持していること。
