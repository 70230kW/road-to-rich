# 下部TOPタブ整理・上位雀士の3D表示

## 変更内容

- 下部ナビだけからTOPを外し、「順位表・対局を記録・対戦履歴・メニュー」の4列に変更します。各画面の「TOPに戻る」、共通メニュー、デスクトップナビのTOPは維持します。
- 小さな3人横並びの表彰台を、一人ずつ大きく表示するスポットライトに置き換えます。上位3名を名前ボタン・左右ボタン・横スワイプで切り替えます。
- 人物の外見は推測せず、各雀士の頭文字・名前・順位を印字した3D麻雀牌を使用します。白い丸角の牌本体、緑の背面、金・銀・銅の台座をThree.jsの実メッシュで構成します。
- フルネーム・段位・半荘数・収支／差額はモデルの外にHTMLで表示し、文字が3Dで隠れないようにします。詳細ボタンは既存の成績モーダルに接続します。
- 順位・同率・差額・段位・期間フィルターの計算は既存実装を利用します。表示人数が1〜2名の場合も対応し、期間変更で選択中の雀士が消えたら先頭に戻ります。

## 描画と代替表示

- Three.jsは表示領域が近づいたときだけ動的に読み込み、常に一つのモデルを使い回します。TOPの牌処理・デザインは変更しません。
- 表示内容・サイズが変わった時だけ描画し、常時アニメーションは行いません。動きを減らす設定でも不要な動きを追加しません。
- 初期化失敗・WebGL非対応・コンテキスト喪失ではCSSの牌へ切り替え、名前・数値・切替・詳細操作は維持します。
- 画面離脱でイベント・監視・予約フレーム・ジオメトリ・材質・テクスチャ・WebGLコンテキストを解放します。
- スワイプは選択だけを変え、詳細を誤って開きません。縦スクロール・キャンセル操作では切り替えません。

## 検証

- ナビの4ボタン、TOP復帰、入力下書きと既存遷移。
- 切替・同率順位・金額表示・フィルター後の選択復帰・0〜3人・長い表示名・詳細モーダル。
- 遅延読み込み・初期化失敗・コンテキスト喪失・画面外の描画抑止・アンマウント時の解放。
- GPU境界をモックし、実メッシュの厚み・カメラ範囲・フレーム集約・全GPU資源の解放を検証。これは実GPUの画像検証ではありません。
- 型チェック・ビルド・lint・テストを実行。実ブラウザー／iPhone上の質感・レスポンシブ表示の目視は環境接続制限により未確認です。
