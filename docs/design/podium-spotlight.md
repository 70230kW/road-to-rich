# リーグホーム導線・上位雀士の横スライドと3D表示

## 変更内容

- 下部ナビは「リーグホーム・順位表・対局を記録・対戦履歴・メニュー」の5列です。左端は既存のリーグホームへ直接移動します。独立TOPへの「TOPに戻る」、共通メニュー、デスクトップナビは維持します。
- 上位3名を一人ずつ大きく表示し、戦績側の横スワイプ、名前ボタン、左右ボタン／キーで切り替えます。指に追従して動き、TOPと同じ減衰ばねで吸着します。連続位置を使用し、1→2→3→1および逆方向に循環します。
- スマホを含め左半分に戦績、右半分に牌を置きます。戦績はフルネーム・段位・半荘数・収支／差額・トップ率・連対率・平均順位です。割合は既存のフォーマッターで小数第一位まで表示します。
- 人物の外見は推測せず、各雀士の頭文字・名前・順位を印字した3D麻雀牌を使用します。白い丸角の牌本体、緑の背面、金・銀・銅の台座をThree.jsの実メッシュで構成します。
- フルネーム・段位・半荘数・収支／差額はモデルの外にHTMLで表示し、文字が3Dで隠れないようにします。詳細ボタンは既存の成績モーダルに接続します。
- 順位・同率・差額・段位・期間フィルターの計算は既存実装を利用します。表示人数が1〜2名の場合も対応し、期間変更で選択中の雀士が消えたら先頭に戻ります。

## 描画と代替表示

- Three.jsは表示領域に入ったときだけ動的に読み込みます。上位雀士ごとに最大3つのモデルを保持し、同じ雀士へ戻った際の向きを保持します。ループのための複製モデルは作りません。TOPの牌処理・デザインは変更しません。
- 牌の操作領域は順位切替から分離し、上下左右のドラッグで全方向へ回転します。カメラ基準のクォータニオンを使い、上下の回転角にも制限を設けません。矢印キーでも回転でき、正面に戻すボタン／Homeキーで初期姿勢へ戻せます。
- 戦績側では縦スクロールを許可し、全方向回転に必要なタッチ操作の制限は牌の領域だけに限定します。ドラッグから成績詳細へ誤遷移しません。
- 表示内容・サイズ・回転操作が変わった時だけ描画し、常時アニメーションは行いません。画面外では描画を抑止します。動きを減らす設定では順位切替の吸着アニメーションを省略し、直接の回転操作は維持します。
- 初期化失敗・WebGL非対応・コンテキスト喪失ではCSSの牌へ切り替え、名前・数値・切替・詳細操作は維持します。
- 画面離脱でイベント・監視・予約フレーム・ジオメトリ・材質・テクスチャ・WebGLコンテキストを解放します。
- スワイプは選択だけを変え、詳細を誤って開きません。縦スクロール・キャンセル操作では切り替えません。

## 検証

- ナビの5ボタン、左端のリーグホームと選択表示、TOP復帰、入力下書きと既存遷移。
- 切替・同率順位・金額表示・フィルター後の選択復帰・0〜3人・長い表示名・詳細モーダル。
- 遅延読み込み・初期化失敗・コンテキスト喪失・画面外の描画抑止・アンマウント時の解放。
- 指追従・複数周のループ・逆方向／途中反転・吸着後の停止・減少モーション・選択外のinert化・ポインター操作とキー操作の分離を検証。
- GPU境界をモックし、実メッシュの厚み・全方向回転／正面復帰・カメラ範囲・フレーム集約・全GPU資源の解放を検証。132/163/340/470px幅のモデル領域で、複数姿勢の全頂点が画角内に収まることを確認します。これは実GPUの画像検証ではありません。
- 型チェック・ビルド・lint・テストを実行。実ブラウザー／iPhone上の質感・レスポンシブ表示の目視は環境接続制限により未確認です。

## プレビューでの確認項目

- 320/390/768/1024pxの画面幅で、戦績と3Dが左右に収まり、長い名前と金額が読めること。
- 戦績の横スワイプ／縦スクロールと牌の上下左右回転が干渉しないこと。
- 3→1と1→3、連打／方向転換を繰り返しても牌やカードが飛ばないこと。
- 牌の裏面・上下面まで回せて、正面へ戻せること。切替後も同じ雀士の向きが残ること。
- キーボード、動きを減らす設定、WebGLなしで順位切替と成績詳細が使えること。
