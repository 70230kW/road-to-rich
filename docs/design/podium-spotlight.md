# リーグホーム導線・上位雀士の横スライドと3D表示

## 変更内容

- 下部ナビは「リーグホーム・順位表・対局を記録・対戦履歴・メニュー」の5列です。左端は既存のリーグホームへ直接移動します。独立TOPへの「TOPに戻る」、共通メニュー、デスクトップナビは維持します。
- 上位3名を一人ずつ大きく表示し、戦績・牌の両側の横スワイプ、名前ボタン、左右ボタン／キーで切り替えます。指に追従して動き、TOPと同じ減衰ばねで吸着します。連続位置を使用し、1→2→3→1および逆方向に循環します。
- スマホを含め左44%に戦績、右56%に大きな牌を置きます。戦績はフルネーム・段位・半荘数・収支／差額・トップ率・連対率・平均順位です。割合は既存のフォーマッターで小数第一位まで表示します。
- 人物の外見は推測せず、各雀士の頭文字・名前・順位を印字した3D麻雀牌を使用します。白い丸角の牌本体、緑の背面、金・銀・銅の台座をThree.jsの実メッシュで構成します。
- フルネーム・段位・半荘数・収支／差額はモデルの外にHTMLで表示し、文字が3Dで隠れないようにします。詳細ボタンは既存の成績モーダルに接続します。
- 順位・同率・差額・段位・期間フィルターの計算は既存実装を利用します。表示人数が1〜2名の場合も対応し、期間変更で選択中の雀士が消えたら先頭に戻ります。

## 描画と代替表示

- Three.jsは表示領域に入ったときだけ動的に読み込みます。上位雀士ごとに最大3つのモデルを再利用し、ループのための複製モデルは作りません。TOPの牌処理・デザインは変更しません。
- 牌の自由回転、回転用のポインターキャプチャ、専用キー操作、「正面に戻す」ボタンを削除しました。牌も戦績も同じ横スワイプ領域です。牌の向きは緑の背面と厚みが見える固定角度にします。
- 自由回転用の大きなカメラ余白をなくし、固定角度の全メッシュ頂点を使って画角を計算します。各辺に5%以上の余裕を確保し、牌を大きく見せます。台座を小さく・低くし、回転説明・ボタンのスペースもモデル表示に使います。
- 牌の上でも縦スクロール・ピンチズームを許可します。ドラッグから成績詳細へ誤遷移しません。
- 表示内容・サイズが変わった時だけ描画し、常時アニメーションは行いません。画面外では描画を抑止します。動きを減らす設定では順位切替の吸着アニメーションを省略します。
- 正常な読み込み中は簡易牌を出さず、最初の描画が成功してから3Dを表示します。読み込み中も選択操作は使えます。
- 初期化失敗・WebGL非対応・コンテキスト喪失ではCSSの牌へ切り替え、名前・数値・切替・詳細操作は維持します。
- 画面離脱でイベント・監視・予約フレーム・ジオメトリ・材質・テクスチャ・WebGLコンテキストを解放します。
- スワイプは選択だけを変え、詳細を誤って開きません。縦スクロール・キャンセル操作では切り替えません。

## 検証

- ナビの5ボタン、左端のリーグホームと選択表示、TOP復帰、入力下書きと既存遷移。
- 切替・同率順位・金額表示・フィルター後の選択復帰・0〜3人・長い表示名・詳細モーダル。
- 遅延読み込み・初期化失敗・コンテキスト喪失・画面外の描画抑止・アンマウント時の解放。
- 指追従・複数周のループ・逆方向／途中反転・吸着後の停止・減少モーション・選択外のinert化・ポインター操作とキー操作の分離を検証。
- 3D表示・読み込み中・非対応時のすべてで、牌側からの横スワイプが雀士切替になること、縦操作を妨げないこと、成績詳細への誤遷移がないことを検証します。
- GPU境界をモックし、実メッシュの厚み・固定角度・カメラ範囲・フレーム集約・全GPU資源の解放を検証。159×320、198×320、390×475、531×510、470×310pxのモデル領域で全頂点が画角内に収まり、スマホでは牌自体が列幅の75%以上を使うことを確認します。これは実GPUの画像検証ではありません。
- 型チェック・ビルド・lint・テストを実行。実ブラウザー／iPhone上の質感・レスポンシブ表示の目視は環境接続制限により未確認です。

## プレビューでの確認項目

- 320/390/768/1024pxの画面幅で、戦績と3Dが左右に収まり、長い名前と金額が読めること。
- 戦績・牌のどちらでも横スワイプで切り替わり、縦操作でページがスクロールすること。
- 3→1と1→3、連打／方向転換を繰り返しても牌やカードが飛ばないこと。
- 右側の牌が十分に大きく、左の長い名前・金額・戦績が隠れないこと。回転説明やリセットボタンがないこと。
- キーボード、動きを減らす設定、WebGLなしで順位切替と成績詳細が使えること。
