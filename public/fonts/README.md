The provider-generated subset contains the four labels `順位表`, `対局入力`, `ダッシュボード`, and `段位` (plus supporting glyphs). No font outlines were modified locally. Regenerate the subset and its CSS unicode-range if those names change.

The CSS-only alias `Jankane TOP Mincho` deliberately isolates the font from the existing league-screen font stack. It applies to the TOP hero titles and menu-name labels, not descriptions, English eyebrows, numbers, actions, or tile artwork. The original font metadata is unchanged.

The font is served from the app's own origin: no Adobe account, runtime font CDN request, or additional package is required. `font-display: swap` keeps navigation readable while loading, with system Mincho fallbacks if loading fails.
